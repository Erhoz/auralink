# AuraLink icon

Original AuraLink mark created through Superdesign, approved by the user. Cyan `#06b6d4`, violet `#8b5cf6`, white and navy `#0c0e14`. No manufacturer logos.

[Design canvas](https://superdesign.dev/teams/842e60dc-7014-4de8-ab76-39113989a1ea/projects/f3e0cbd7-def5-4634-8abd-c34ac70b1844), draft `0d8d3290-a494-4078-8626-f46acfc4f27c`.

`AuraLink.svg` is the vector source. `AuraLink.ico` contains 16/20/24/32/40/48/64/128/256-pixel PNG frames. `tools/BuildIcon.cs` reproduces the vector geometry through GDI+ and writes the ICO plus a small-size preview. The executable and installer embed the ICO as their Windows icon resource.
